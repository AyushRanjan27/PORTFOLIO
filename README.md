# PORTFOLIO

This repository contains a personal portfolio site with a Node backend and a Vite + React frontend.

Structure
- `BACKEND/` — Express server (optional)
- `FRONTEND/vite-project/` — Vite + React frontend (site)

Run locally (frontend)
1. cd FRONTEND/vite-project
2. npm install
3. npm run dev

Build
1. cd FRONTEND/vite-project
2. npm run build

Deploy
- This repo includes a GitHub Actions workflow that builds the Vite site and publishes the `dist` folder to GitHub Pages (branch `gh-pages`).
- Expected Pages URL: https://AyushRanjan27.github.io/PORTFOLIO

Notes
- If you want the frontend deployed from a different path or a separate domain, tell me and I will adjust the workflow and repository settings.
